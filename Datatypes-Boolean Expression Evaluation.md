
# Ex 1:1(b)Datatypes-Boolean Expression Evaluation in Python

## 🎯 Aim
To write a Python program that evaluates and prints the results of boolean and arithmetic expressions involving `True` and `False`.

## 🧠 Algorithm
1. Set variable `a` to the result of the expression `False == True`.
2. Set variable `b` to the result of the expression `False == 0`.
3. Set variable `c` to the result of the expression `False + True`.
4. Set variable `d` to the result of the expression `False + 5`.
5. Print the value of `a` with the label "a is".
6. Print the value of `b` with the label "b is".
7. Print the value of `c` with the label "c:".
8. Print the value of `d` with the label "d:".

## 💻 Program
```
a =(False == True)
b =(False== 0)
c = False + True
d =False + 5
print("a is", a)
print("b is", b)
print("c:", c)
print("d:", d)
```
