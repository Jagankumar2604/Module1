# 1(c)Datatypes-Character Literal in Python

## 🎯 Aim
To write a Python program that prints the characters `'S'` and `'k'` using character literals.

## 🧠 Algorithm
1. Print the character `'S'`.
2. Print the character `'k'`.

## 🧾 Program
```
a='S'
b='k'
print(a)
print(b)
```
